# UI/UX Engineering

Inspect existing screens, design tokens, component library, typography, spacing, color, iconography, and interaction patterns before designing. Avoid generic template-like interfaces. Establish hierarchy, readable density, consistent spacing, and purposeful visual emphasis. Design responsive states and realistic content. Include hover, focus, active, disabled, loading, empty, and error states where relevant. Use meaningful motion only; respect reduced-motion preferences. Maintain WCAG-aware contrast, keyboard access, semantic structure, and screen-reader labels. Do not invent a new design system if one exists.
