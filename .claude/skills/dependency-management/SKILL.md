# Dependency Management

Inspect manifests, lockfiles, runtime compatibility, license, maintenance status, security advisories, and transitive impact. Prefer existing dependencies and platform capabilities. Do not install or upgrade packages merely for convenience. Keep lockfiles consistent with the package manager. Test affected functionality and report breaking changes and risk. Ask before major upgrades or license-sensitive additions.
