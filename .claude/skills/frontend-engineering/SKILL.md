# Frontend Engineering

Detect framework, version, routing, state management, data fetching, styling, testing, and build conventions. Follow existing component boundaries and patterns. Consider loading, empty, error, success, and permission states. Ensure responsive behavior, keyboard navigation, semantic HTML, accessible labels, focus handling, and reduced-motion support. Avoid unnecessary client-side state, effects, dependencies, and duplicated server state. Check bundle and rendering implications. Verify with the project's tests, lint, typecheck, and build commands.
