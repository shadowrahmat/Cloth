# Technical Documentation

Inspect the implementation and existing docs before writing. Keep documentation aligned with actual behavior and versions. Prefer updating canonical docs. Include prerequisites, commands, configuration variable names (not secret values), examples, error handling, and operational notes as relevant. Label assumptions and unverified behavior. Avoid duplicating existing docs.
